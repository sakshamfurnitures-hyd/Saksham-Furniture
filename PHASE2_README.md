# Saksham Furniture — Phase 2 Homepage

This is the approved Phase 1 Next.js + Tailwind design extended with a complete **homepage layout**.

Included:
- Five responsive existing image banners in an interactive carousel.
- Nine category cards. Beds, Sagwan Bed and Upholstery Bed retain the three approved images; six others retain previous images.
- Room collections, brand section, Google Maps review link (no fabricated live reviews), custom furniture enquiry.
- Existing header, mobile menu, footer, original logo and brand palette.

**Not yet implemented:** Google Sheets live catalogue, working category/product pages, product-specific social previews, real-time Google review cards, PWA. Category links still lead to a placeholder page. These are subsequent phases. Do not replace the production website yet.

Local testing: `npm install` then `npm run dev`. For Netlify connect the GitHub repository and use `npm run build`; do not connect the production domain until verified.

Build could not be executed in the authoring environment because node_modules / Next.js dependencies are not installed; validate on your computer or Netlify before launch.
